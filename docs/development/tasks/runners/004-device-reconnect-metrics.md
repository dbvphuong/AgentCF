## PC-004

- [x] **PC-004 — Kết nối lại giữ PC, thao tác rõ ràng và telemetry thật** — Xong | Bug/Feature
  - Nguyên nhân: nút Kết nối PC có sẵn chỉ gửi tên/Workspace, Server luôn tạo ID mới; session có thể ghi đè fingerprint thành null. Không thể dùng tên/OS để tự gộp máy.
  - Web quick-connect gửi `target_runner_id`, Server ràng buộc Workspace/PC còn tồn tại. Reconnect giữ ID/tên/tham chiếu, đổi credential và revoke session cũ trong transaction; chặn Attempt đang thực thi dở dang (`claimed`/`running`/`reconciling`), cho phép Reconnect khi Run đang queued để worker kéo việc về thực thi. Disconnect thu hồi credential/session, giữ PC/config/file; chặn mọi Run/Attempt chưa kết thúc.
  - Client 0.3.0: `device_id` hash Windows MachineGuid (fallback ID cài đặt), `device_key` ngẫu nhiên bảo vệ DPAPI riêng. Pair mới nhận diện máy; known-device không có target chỉ reconnect nếu có proof đúng. Session đã xác thực có thể gắn identity cho PC legacy ngay khi nâng cấp, không phải ghép nối lại. Không lộ key/hash trên API list/detail. Không dùng tên máy làm khóa và không xóa fingerprint khi session không truyền.
  - Migration 020: identity/proof-hash, unique active `(workspace_id,device_id)`, pairing target; không gộp dữ liệu legacy dựa trên tên. PC đã Xóa không tự phục hồi; ghép lại sau Xóa vẫn tạo identity lịch sử mới, chỉ một dòng còn hoạt động cho device.
  - Cột Thao tác có Kết nối khi offline hoặc Hủy kết nối khi online/busy, cùng Sửa/Xóa. Bỏ nút dưới tên PC. Hủy có xác nhận, Server chặn nếu còn Run. Poll 5 giây, ngừng poll khi tab ẩn. CPU/RAM cũ không hiện như số liệu live khi offline.
  - Windows CPU lấy delta GetSystemTimes, RAM lấy GlobalMemoryStatusEx; heartbeat gửi % và RAM used/total bytes. Migration 021 lưu dung lượng, API kiểm dùng <= tổng. Phiên mới xóa sample cũ, sample CPU đầu chưa đủ delta để trống; không sinh số giả. UI hiển thị % CPU và RAM used/total GB cùng %.
  - Code: Runner repository/API, desktop `identity.py`/`metrics.py`, ClientSession/daemon/app, ConnectPc/Runners, bootstrap 0.3.0 và OpenAPI generator.
  - Kiểm chứng 2026-11-19: full pytest **274 passed, 1 skipped**; sau bổ sung upgrade qua session, suite Runner + identity/metrics + daemon **20 passed**. Web **21 passed**, TypeScript/Vite build đạt. `pc-connection-actions.cjs`: **passed**, mock API kiểm vị trí/toggle/target ID/telemetry/freshness. OpenAPI **94 schemas, 76 paths, 100 operations** đạt. Build installer **17,703,424 bytes**, Client 0.3.0. Cập nhật 2026-11-20: tách `_require_no_active_execution` cho Reconnect (cho phép nhận việc queued, giải phóng deadlock) và `_require_idle` cho Disconnect; Client hiển thị chi tiết lỗi Server; full pytest **293 passed, 1 skipped**, build installer 17,704,448 bytes.
  - Dữ liệu thật: khi chuẩn bị dọn trùng, hai dòng cũ đã được người dùng xóa và có PC mới đang được Skill tham chiếu. Không xóa hoặc khôi phục lại các ID đó. Giữ PC `pc-d9ae614fe596`, cập nhật Client dưới khóa cài đặt sau xác minh không có Run chưa kết thúc, nạp schema 21. Heartbeat thật: **1 PC**, cùng ID, device bound, Client 0.3.0, CPU **28.1%**, RAM **84.4%**, used **10,723,647,488** / total **12,699,738,112** bytes tại lượt kiểm; không expose device key hash. Số liệu thay đổi theo thời gian.
  - Giới hạn: uniqueness theo Workspace và định danh Windows/cài đặt, không chứng minh phần cứng độc nhất sau clone/reinstall OS. PC legacy chưa có identity cần upgrade bằng credential còn hợp lệ hoặc reconnect qua dòng đã có. Không gộp những máy khác trùng tên. Không ký số/auto-update hoặc nghiệm thu mọi phiên bản Windows từ task này.
